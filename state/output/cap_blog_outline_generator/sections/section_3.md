## SEO Checklist

Use this checklist before and after publishing. The examples below use the primary keyword **“blog post outline generator”**; adapt them to the article’s actual topic rather than forcing irrelevant keywords.

### 1. Keyword and Search Intent

| Element | Requirement | Realistic example |
|---|---|---|
| Primary keyword | Choose one main phrase that closely matches the page topic. Use it naturally in the SEO title, H1, introduction, and one relevant subheading. | Blog post outline generator |
| Search intent | Confirm whether the searcher wants a tool, instructions, a template, or inspiration. Address that need early. | The reader wants a quick outline before drafting a blank-page blog post. |
| Secondary keywords | Add two to four related phrases where they improve coverage. | How to create a blog outline; blog content planner; article structure |
| Audience need | State who the article helps and what problem it solves. | Helps new bloggers organize ideas and publish consistently. |
| Competing pages | Review relevant results to identify missing questions, formats, or examples. | Most results explain headings but provide little practical workflow guidance. |
| Keyword stuffing | Prioritize clarity and natural language. Do not set a keyword-density target or repeat the phrase unnaturally. | “A blog post outline generator” appears where it genuinely supports the topic. |

### 2. On-Page Elements

| Element | Checklist | Realistic example |
|---|---|---|
| SEO title | Keep it descriptive, specific, and generally under 60 characters. Put the main benefit or keyword near the beginning. | Blog Post Outline Generator: Free Planning Tool |
| Meta description | Summarize the value in approximately 150–160 characters and give readers a reason to click. | Create a structured blog post outline in minutes, organize ideas, and turn a blank page into a publish-ready plan. |
| H1 | Use one visible page heading that matches the article’s main promise. | Blog Post Outline Generator for Faster Writing |
| URL slug | Use short, lowercase, hyphenated words. Avoid dates and unnecessary filler. | `/blog-post-outline-generator/` |
| Introduction | Confirm the target problem, intended reader, and main benefit within the opening paragraphs. | Explain how new bloggers can generate a topic, working headings, and a logical content flow. |
| Headings | Use H2s for major sections and H3s for supporting points. Keep the hierarchy sequential. | “Choose a Goal,” “Enter the Topic,” and “Build the Outline.” |
| Direct answer | Provide a concise definition, process, or summary that could be extracted as a snippet. | A simple three-step process: enter a topic, select a goal, and customize the suggested headings. |
| Readability | Use short paragraphs, descriptive subheadings, lists, and familiar language. | Break the setup instructions into five numbered steps. |
| Images and video | Add descriptive alt text to meaningful images. Include captions or transcripts when useful. | Alt text: “Blog post outline displayed in a simple planning table.” |
| Internal links | Link to at least two relevant articles with descriptive anchor text. | “blog content planning workflow” and “how to research a blog topic” |
| External links | Cite authoritative sources for factual claims and link to the original source where possible. | Link to official search-engine guidance when explaining indexing. |
| Structured data | Add schema only when the visible page content supports it. Never mark up invisible FAQs or misleading reviews. | Use Article or SoftwareApplication schema when the page genuinely qualifies. |

### 3. Technical and Publishing Checks

- [ ] The page returns a successful response and is not blocked by `robots.txt`.
- [ ] The canonical URL points to the preferred version of the post.
- [ ] The page is indexable and does not contain an accidental `noindex` directive.
- [ ] The post appears correctly on desktop and mobile.
- [ ] Navigation, images, tables, and call-to-action buttons work.
- [ ] Sources, dates, headings, and author information are accurate.
- [ ] Any claims requiring expertise are reviewed and qualified appropriately.
- [ ] Social sharing information uses a relevant title, description, and image.
