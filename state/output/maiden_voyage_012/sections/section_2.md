### 3. Client Setup Checklist

| ☐ | Task | Completion Standard |
|---|---|---|
| ☐ | Verify client and contact | Legal name, phone, email, and escalation contact confirmed |
| ☐ | Define services | Languages, specialties, modalities, departments, and locations recorded |
| ☐ | Document schedule | Days, shifts, onsite requirements, standby rules, and notice requirements entered |
| ☐ | Confirm credentials | Every requirement linked to evidence, owner, expiration, and renewal method |
| ☐ | Record financial terms | Base rate, overtime, minimum call, cancellation policy, expenses, and payment schedule entered |
| ☐ | Test access | Badges, portals, phone systems, devices, and supervisors tested |
| ☐ | Establish communications | Secure channels and after-hours escalation procedure documented |
| ☐ | Protect information | Confidentiality and minimum-necessary-data rules acknowledged |
| ☐ | Review first assignment | Date, location, arrival instructions, dress requirements, and check-in contact confirmed |

### 4. Weekly Maintenance Checklist

| ☐ | Weekly Task | Completion Standard |
|---|---|---|
| ☐ | Reconcile assignments | Confirmed, tentative, cancelled, and standby shifts match the weekly planner |
| ☐ | Check updates | Schedule, contact, access, and cancellation changes reviewed |
| ☐ | Verify readiness | Credentials, travel, parking, badge, and equipment needs checked |
| ☐ | Submit records | Timesheets or invoices sent by the client’s deadline |
| ☐ | Log follow-ups | Open requests assigned a date and next action |
| ☐ | Update records | Changed terms, contacts, rates, and credential expirations saved immediately |

**Conclusion:** A complete, current client database enables faster weekly scheduling, prevents credential gaps, standardizes billing, and maintains secure client operations.
